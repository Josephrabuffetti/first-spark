# Current artwork

All five shipped raster art assets in v6 were created for First Spark with the built-in image-generation tool. They depict fictional cosmic and planetary imagery. See [ART_DIRECTION.md](ART_DIRECTION.md) for exact file paths and generation prompts.

The borrowed Rawdanitsu and Solar System Scope images used in v4 have been removed from the current game. Their attribution remains in the historical v4 commit; none is required for the new generated artwork on their behalf.

Cloud masks, surface lighting, camera motion, coastal life tints, and synthesized sounds are native game effects. The spark icon is the existing native SVG mark.
